## 📝 Descripción
Este proyecto consiste en el despliegue automatizado de un CMS WordPress utilizando contenedores Docker. Se ha configurado la persistencia de datos y la administración de base de datos vía web.

## 🛠️ Stack Tecnológico
* **Motor:** Docker & Docker Compose
* **CMS:** WordPress (Latest)
* **Base de Datos:** MySQL 8.0
* **Administración:** PhpMyAdmin (solamente para entornos de desarrollo)

## 🚀 IMPORTANTE: Cómo ejecutar este proyecto
1.  Clonar el repositorio.
2.  Ejecutar `docker-compose up -d`.
3.  Acceder a `http://localhost:8080`.
4.  Configura tu blog Wordpress con las credenciales que te has asignado
5.  Comienza a diseñar tu blog.
